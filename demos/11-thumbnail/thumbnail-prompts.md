# Thumbnail demo — 2 filled prompts

> How to use: paste ONE prompt block into an image model (GPT-Image / Gemini / Ideogram / Midjourney v7 / Flux).
> Attach: (1) your own cut-out photo, (2) your platform logo, (3) optionally the layout guide PNG next to this file.
> Bangla text in image models can still come out broken. If any letter is wrong, ask the agent for the
> **"clean-plate" variant** of the same prompt (no text), then type the headline yourself in Canva/Photoshop
> using the exact text in the TEXT LOCK section.

---

## Prompt 1 — Theme: "One-Shot Chapter" (green/emerald)

**Form the student filled**
| Field | Value |
|---|---|
| Class / exam | HSC 2027 (পদার্থবিজ্ঞান ১ম পত্র) |
| Topic / chapter | আদর্শ গ্যাস ও গ্যাসের গতিতত্ত্ব (অধ্যায় ১০) |
| Video type | One-shot full chapter |
| Main hook | পুরো অধ্যায় এক ক্লাসে |
| Badge / ribbon | ONE SHOT CLASS · ১০০% কমন |
| Teacher photo | attached (half-body, arms crossed, smiling) |
| Teacher name | Abir Hasan (sample) |
| Logo | attached (EduBrand) |
| Mood | confident, calm, premium |

**PROMPT (copy everything inside the box)**
```
Create a YouTube thumbnail, 16:9, 1280x720, ultra sharp, high contrast, Bangladeshi EdTech style.

SUBJECT: Use the attached person photo exactly (same face, same clothes, no beautification, no face change).
Place the person as a clean cut-out on the RIGHT 38% of the frame, waist-up, facing slightly toward the text,
confident smile, arms crossed. Add a thin white rim-light outline (6px) around the cut-out and a soft shadow.

BACKGROUND: deep emerald-to-black radial gradient (center #0E5E3A, edges #03140C), subtle faint
physics doodles in the background at 8% opacity (gas molecules, piston cylinder, PV=nRT), light bokeh,
a diagonal light streak from top-left. No clutter behind the face.

LEFT TEXT BLOCK (left 58%, vertically centered, left aligned, 6% safe margin):
  line 1 (small pill tag, white text on red #E3262E, rounded): "পদার্থবিজ্ঞান ১ম পত্র"
  line 2 (huge, 3D extruded bold Bangla, white with 8px black outline + yellow #FFD60A inner gradient): "আদর্শ গ্যাস"
  line 3 (large, white, bold): "ও গ্যাসের গতিতত্ত্ব"
  line 4 (ribbon banner, black text on bright yellow #FFD60A, slight tilt -3°): "ONE SHOT CLASS"
  bottom-left stamp (red circle stamp, white text, slight rotation): "১০০% কমন"
TOP-LEFT: place the attached logo, small (height ≈ 9% of frame), with 4% margin.
TOP-RIGHT: small rounded badge "HSC 27" white on black.
BOTTOM (under the person): name tag, black glass card, white text "Abir Hasan" + small grey line "Physics Mentor".

TYPOGRAPHY: heavy Bangla display face similar to "Li Ador Noirrit Bold"/"Hind Siliguri Bold", tight line spacing,
perfect Bangla conjuncts (গ্যা, ত্ত্ব must be correct). Max 3 font sizes. All text readable at 160px width.

TEXT LOCK — render these strings EXACTLY, character by character, nothing else:
"পদার্থবিজ্ঞান ১ম পত্র" | "আদর্শ গ্যাস" | "ও গ্যাসের গতিতত্ত্ব" | "ONE SHOT CLASS" | "১০০% কমন" | "HSC 27" | "Abir Hasan" | "Physics Mentor"

AVOID: extra words, fake logos, watermarks, misspelled Bangla, distorted hands/face, text over the face,
more than 2 accent colors, low contrast, small text.
```

**Clean-plate variant (if the model breaks Bangla):** same prompt, replace the LEFT TEXT BLOCK and TEXT LOCK with
`Leave the left 58% empty for text: keep only the gradient, glow and doodles there. Do not render any letters.`
